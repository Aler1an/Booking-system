# Book&Study – система бронювання слотів

## Короткий опис
Book&Study — це веб-система, що дозволяє користувачам бронювати часові слоти для занять, консультацій або використання ресурсів (наприклад, аудиторій, комп’ютерних класів або робочих місць у бібліотеці).  
Система забезпечує зручний інтерфейс для створення, перегляду та скасування бронювань, а також базові функції авторизації для користувачів і адміністраторів.

## Ролі користувачів
- Користувач (Student) — може переглядати доступні слоти, бронювати, скасовувати власні бронювання.  
- Адміністратор (Admin) — може створювати/видаляти слоти, переглядати всі бронювання, керувати користувачами.

## Основні сценарії використання
1. Користувач відкриває сторінку і переглядає доступні часові слоти.  
2. Користувач натискає "Book" для вибраного часу.  
3. Система перевіряє доступність і створює бронювання.  
4. Адміністратор входить у систему та додає нові часові проміжки для бронювання.  
5. Користувач скасовує бронювання через власний профіль.

## Функціональні вимоги
- Реєстрація та авторизація користувачів.  
- Перегляд списку доступних слотів.  
- Створення та скасування бронювання.  
- Панель адміністратора для управління слотами.  
- API для клієнтського застосунку.

## Нефункціональні вимоги
- Система повинна відповідати на запити не довше 2 секунд.  
- Дані мають зберігатись у реляційній БД (SQLite або PostgreSQL).  
- Інтерфейс має бути зручним і доступним з мобільних пристроїв.  
- Використання REST API між клієнтом і сервером.

## Обмеження
- Система не підтримує оплату бронювання.  
- Немає push-сповіщень або email-нотифікацій.  
- Користувачі не можуть змінювати бронювання інших користувачів.
