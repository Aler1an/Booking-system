# ADR 0001 — Вибір архітектурного стилю

**Дата:** 2025-11-7  
**Статус:** Accepted  
**Автор:** Максим Яценюк

## Контекст
Проєкт "Booking System" розробляється командою з двох учасників.  
На даному етапі система має одну базу даних, просту структуру API і невелику кількість бізнес-контекстів.

## Рішення
Обрано стиль **модульного моноліту**.

## Альтернативи
- Мікросервіси — відхилено на цьому етапі через складність підтримки, деплою та відсутність потреби в незалежному масштабуванні.

## Наслідки
- Усі модулі живуть у спільному репозиторії.
- Міжконтекстні виклики виконуються напряму через код.
- Можливість майбутнього переходу на мікросервіси зберігається.

## Умови перегляду
Повернемось до питання розбиття на сервіси, якщо:
- кількість модулів перевищить 5;
- зросте кількість розробників;
- виникне потреба у незалежному масштабуванні частин системи.
