# ADR 0002 — Шарова архітектура проєкту

## Рішення
Проєкт поділено на три рівні:
- api/ — маршрути Express.js (контролери), приймають запити, повертають DTO.
- service/ — бізнес-логіка (CRUD, валідація, мапінг DTO ↔️ domain).
- domain/ — сутності з бізнес-правилами.

## Правила
- api/ не звертається безпосередньо до БД;
- Всі перевірки виконуються у service/;
- domain/ не знає про Express або HTTP.

## Напрямок залежностей
api → service → domain
