# Глосарій термінів — Book&Study

| Термін | Визначення |
|--------|-------------|
| User | Особа, яка має обліковий запис у системі. Може мати роль student або admin. |
| Admin | Користувач, який може створювати, редагувати або видаляти слоти. |
| Student | Користувач, який може бронювати доступні слоти. |
| Slot | Часовий проміжок, доступний для бронювання (наприклад, 10:00–11:00 у вівторок). |
| Booking | Резервація конкретного слоту певним користувачем. |
| Resource | Об’єкт, який можна бронювати (наприклад, аудиторія або викладач). |
| Notification | Повідомлення користувачу про створення, скасування чи зміну бронювання. |
| Auth | Механізм входу користувача у систему (login/register). |
| Status | Стан бронювання або слоту (`available`, booked, `cancelled`). |
| Session | Період активності користувача після авторизації. |
