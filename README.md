# Booking-system

📌 **Booking-system** — це повноцінна система бронювання кімнат з бекендом, фронтендом і підтримкою контейнеризації для розгортання.  
Цей проєкт покликаний надати гнучке рішення для управління резервуванням кімнат/ресурсів для користувачів і адміністраторів.

## 🧩 Основні компоненти

Проєкт має кілька важливих частин:

- 🖥️ **frontend** — клієнтська частина (UI)  
- 🧠 **backend** — серверна частина (API)  
- 📦 **docker-compose.yml** — для запуску сервісів через Docker  
- 📄 **docs/** — документація проєкту  
- ☸️ **k8s/** — Kubernetes-конфігурації для розгортання  
- 📊 **load-generator/** — інструменти для навантажувального тестування  
- 📌 **observability-demo/** — приклади для моніторингу/логування

> Розподіл директорій свідчить про **повноцінну архітектуру з фронтендом і бекендом** та можливістю розгортання в продакшн-середовищі. :contentReference[oaicite:1]{index=1}
